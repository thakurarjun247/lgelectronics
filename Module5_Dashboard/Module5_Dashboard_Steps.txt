the dashboard updates.

STACK (all free, all no-code, all feasible in n8n)

- Dashboard: Looker Studio (native Google Sheets connector, auto-refresh)
- Same Google account used for Gemini / NotebookLM.

FINAL FLOW

STEP 2 — CONNECT GOOGLE ACCOUNT TO n8n  [DONE]
=====================================================================
1. In the Module 4 orchestration workflow -> add node -> search "Google Sheets".
2. In the node: Credential -> "Sign in with Google" -> complete the Google popup ->
   allow access (Sheets + Drive scopes). Credential saved as "Google Sheets account".
   - Gotcha: if the popup is blocked, allow popups for the n8n domain and retry.
   - This authorizes n8n to read/write the signed-in Google account's Sheets.
3. Node config so far:
   - Resource = Sheet Within Document
   - Operation = Append Row   (use Append Row, NOT "Append or Update Row" — Append
     Row does not need a "column to match on")
   - Document = From list -> IM500_Maintenance_Log
   - Sheet = From list -> Sheet1
   - Mapping Column Mode = Map Each Column Manually
